# YÊU CẦU ĐẦU RA

## Phần 1: 

#### 1. Cơ chế chia nhỏ:

- Là quá trình AI chia nhỏ 1 đoạn văn bản thành các token rồi đưa vào bộ xử lý

#### 2.Lý do AI xử lý nhanh hơn ở Markdown:

- Markdown là định dạng thuần văn bản nên chỉ sử dụng các ký tự gọn gàng ,tốn ít token

- HTML đầy thẻ mở/đóng nên dễ sinh ra nhiều token dư thừa

-->Vì Markdown tốn ít token hơn nên AI sẽ xử lý nhanh hơn

## Phần 2: So sánh & đánh giá

### Bảng so sánh

|Tiêu chí|Markdown|HTML|
|-|-|-|
|Số lượng ký tự cho cùng một định dạng|Cực kỳ ngắn gọn|Rườm rà, dài dòng|
|Độ dễ đọc đối với người dùng|Rất cao, trực quan|Thấp, dễ rối mắt|
|Hiệu quả xử lý của AI|Tối ưu, tiết kiệm token|Lãng phí token nghiêm trọng|

### Đánh giá

Hệ thống **Greenteach** nên  lựa chọn Markdown thì sẽ tối ưu hơn

Lý do lựa chọn:

1. Tiết kiệm token giúp AI xử lý nhanh hơn

2. Tiết kiệm được chi phí vận hành
